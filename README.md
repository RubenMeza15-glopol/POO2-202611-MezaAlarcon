# Sistema de Registro Académico UNA-PUNO

**Curso:** Programación Orientada a Objetos II (SIS206)  
**Universidad:** Universidad Nacional del Altiplano — Puno  
**Periodo:** 2026-II

## Descripción

El proyecto consiste en desarrollar un sistema de registro académico que permita organizar la información de los estudiantes, los cursos y las calificaciones.

## Problema

La información académica necesita organizarse de manera clara para facilitar el registro, la consulta y el seguimiento del rendimiento de los estudiantes.

## Objetivo

Diseñar e implementar progresivamente un sistema académico aplicando los principios de la programación orientada a objetos.

## Usuarios principales

- **Estudiantes:** consulta de información académica y calificaciones.
- **Docentes:** gestión de calificaciones.
- **Personal administrativo:** organización de información académica.

## Clases iniciales

- **Estudiante:** código, nombre y apellido.
- **Curso:** código, nombre, créditos, ciclo y descripción.
- **Nota:** curso y calificación.

## Desarrollo

El proyecto se ampliará progresivamente durante el curso, incorporando los conceptos de programación orientada a objetos estudiados en cada semana.
